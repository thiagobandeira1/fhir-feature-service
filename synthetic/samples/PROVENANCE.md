# Sample bundle provenance

Every file in this directory is **fully synthetic** — generated by
[Synthea](https://github.com/synthetichealth/synthea) (MITRE's synthetic patient generator).
No real patient data exists anywhere in this repository. The bundles are safe to commit, to
share publicly, and to process with cloud LLMs.

## Generation parameters

| Parameter | Value |
|---|---|
| Generator | `synthetichealth/synthea`, official `synthea-with-dependencies.jar` release |
| Generated on | 2026-08-30 |
| Java runtime | Temurin 21.0.12.1 JRE, `-XX:+UseParallelGC` |
| Seed | `20260830` (deterministic; rerunning with the same jar + seed reproduces the cohort) |
| Population | 2,000 living patients (3,726 total including deceased) |
| Geography | Florida, USA |
| Age range | 65–95 (Medicare-shaped cohort for the VBC portfolio) |
| History | `exporter.years_of_history = 10` |
| Profile | US Core Implementation Guide export enabled |
| Format | FHIR R4 `Bundle` (type `transaction`), one patient per bundle |

## Persona selection

Five bundles were curated from the full run, each earning its slot for a specific test need:

| File prefix | Persona | Why it is here |
|---|---|---|
| `Chet188` | Smallest living patient | Fast-path fixture: cheapest full ingest for unit/integration loops |
| `Sheryl275` | HbA1c present | Lab-feature coverage: `latest_hba1c` and LOINC observation handling |
| `Tony646` | Type 2 diabetes | Chronic-condition flags, statin orders, BP panels — the golden-test workhorse |
| `Meredith572` | Cancer screening history | Mammogram/colonoscopy/FOBT procedure- and lab-date features |
| `Kayce253` | Deceased | Death-date edge cases: `is_deceased`, no events after death, panel exclusions |

## Packaging

- Compressed with `gzip -9` (level 9); loaded transparently by the test fixtures and the
  ingest CLI (`.json.gz` supported alongside `.json`).
- Filenames are Synthea's native `<Name><digits>_<Surname><digits>_<uuid>.json.gz` pattern;
  the trailing UUID is the FHIR `Patient.id`.
- The rest of the 3,726-bundle run is **not** committed — only these five curated personas.
  `.gitignore` blocks bulk data directories, and CI guards against stray data files.
